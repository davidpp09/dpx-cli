# @dpx-cli/dpx

**Tu mentor senior de desarrollo, en la terminal.** Tres modos —`code` (agente autónomo), `hack` (rápido con criterio), `learn` (tutor socrático)— con enfoque por stack, impulsado por DeepSeek.

```bash
npm install -g @dpx-cli/dpx
```

```bash
dpx learn          # el tutor socrático
dpx code           # agente que implementa, ejecuta y corrige
dpx hack           # construir rápido con criterio
```

## Requisitos

- **Windows x64** (Mac/Linux: próximamente).
- Una API key de DeepSeek en `~/.dpx/.env`:

  ```env
  DEEPSEEK_API_KEY=sk-...
  ```
